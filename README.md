# Scorched Tanks

A Scorched Earth-style artillery game that runs in a single HTML file. No build step, no dependencies.

- 2–4 tanks, any mix of humans (shared keyboard, taking turns) and CPU opponents
- Destructible terrain, wind, and three weapons (Missile, Big Bomb, Triple)
- Land a hit and spin the prize wheel for a one-shot special attack:
  Nuke, MIRV, Dirt Bomb, Bouncer, Airstrike, Teleport, Vampire

## Play

Open `index.html` in a browser.

| Key | Action |
|---|---|
| ← → | Aim |
| ↑ ↓ | Power (hold Shift for fine) |
| A D | Drive (limited fuel) |
| 1 2 3 | Choose weapon |
| Space | Fire |
| T / M / P | Aim assist / sound / pause |
| Esc | Menu |
